# test_project

Небольшая консольная анимация бегущей свинки.

## Запуск

```bash
chmod +x /home/runner/work/test_project/test_project/run_pig.sh
/home/runner/work/test_project/test_project/run_pig.sh
```

## Опции

- `-d, --delay` — задержка между кадрами в секундах (например, `0.05`)
- `-l, --loops` — количество проходов по экрану (по умолчанию бесконечно)
- `-h, --help` — показать справку

Пример:

```bash
/home/runner/work/test_project/test_project/run_pig.sh --delay 0.04 --loops 3
```
